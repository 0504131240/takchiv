## ספירת כניסות לדשבורד

בכל פתיחה של האפליקציה נספרת כניסה למייל המחובר ב-`logins/{email}` (שם, מייל, כמה פעמים ומתי לאחרונה). רק הבעלים יכול לקרוא, והנתונים מוצגים בדשבורד הכניסות (`/dashboard.html` באתר המנגל). צריך להדביק מחדש את `firestore.rules` ב-Firebase, עם המייל של הבעלים במקום `__OWNER_EMAILS__`.
